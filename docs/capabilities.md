# Flairy 能力指南

> 本文档描述 Flairy 桌面助手当前具备的能力,供回答用户「Flairy 能做什么 / 怎么用」类问题时参考。请根据用户的问题挑选相关内容、用用户的语言组织回答;文档中没有提到的能力,请如实告知不确定,不要虚构。

## Flairy 是什么

Flairy 是一个开箱即用的桌面 AI 助手(支持 macOS 和 Windows)。安装后登录账号即可使用,无需任何配置——模型、联网能力等都由管理端统一提供。你的对话会在多台设备间自动同步。

## 对话与问答

- **自然对话**:回答问题、写作、翻译、分析、头脑风暴等,回复实时逐字呈现,支持代码高亮、表格、图表卡片等富文本形式。
- **联网搜索与网页阅读**:Flairy 可以搜索互联网、打开并阅读指定网页,回答中会标注 `[n]` 来源引用,可点击查看原文。
- **看懂图片**:把图片粘贴或拖入输入框,Flairy 能理解图片内容并结合上下文回答。
- **长对话不断线**:对话很长时会自动压缩早期内容,保持连续;偶发的网络错误会自动重试。
- **多个对话并行**:切到别的对话或收起窗口,后台对话继续生成,不会中断。
- **切换模型**:输入框可以选择本次对话使用的模型(可选范围由管理员提供),悬停可查看每个模型的详情。
- **记忆**:告诉 Flairy「记住我喜欢……」,它会长期记住,并在所有设备上生效;也可以让它忘掉某条记忆。
- **计划卡片**:处理多步骤任务时,输入框上方会显示实时任务清单,展示进行到哪一步。

## 项目(文件夹工作区)

把电脑上的一个文件夹交给 Flairy,围绕它展开工作:

- 侧边栏可浏览文件夹内的文件树并预览文件内容。
- 输入框里输入 `@` 可快速搜索并引用项目中的文件。
- Flairy 可以读取、修改文件,或运行命令来完成任务——**所有可能改动电脑的操作都会先弹出确认卡片,你同意后才执行**。
- 项目对话保存在本机,不会同步到其他设备(普通聊天会同步)。

## 定时任务

在任何对话里直接说,例如「每天早上 9 点给我总结一下科技新闻」:

- Flairy 会自动创建定时任务,到点后在**同一个对话**里执行并回复结果。
- 支持一次性任务(「明晚提醒我……」)和周期任务。
- 「设置 → 定时任务」里可以查看、暂停、恢复或删除所有任务。

## Telegram 远程使用

在设置中配对一个 Telegram 机器人后,可以在手机上随时随地使用 Flairy:

- 消息发给机器人,回复会实时流式更新。
- 需要确认的操作会以按钮形式发到 Telegram,点一下即可批准或拒绝。
- 发送 `/sessions` 可列出桌面端的对话,选择任意一个接着聊——手机与电脑无缝衔接。
- 新的 Telegram 聊天默认是轻量对话,适合随手提问。

## 软件项目托管(进阶)

带着一个软件想法来,Flairy 可以替你推进整个项目:

- 和你讨论并整理出需求文档与技术方案,创建 GitHub 仓库,把工作拆解成一个个任务。
- 把每个任务派发给你电脑上的编码助手(支持 Claude Code、Codex、Gemini CLI、OpenCode)去实现并提交 Pull Request。
- 由另一个助手交叉评审代码(只提意见,合并永远由你决定),你确认合并后自动推进下一个任务。
- 对话中以实时卡片展示任务进度,「任务」面板可查看详细日志、中止任务、打开 PR 链接。
- GitHub 登录只需在设置里输入一次性代码,无需其他配置;你的 GitHub 凭证不会交给任何编码助手。
- 对已有项目,小需求(如修 bug)是一个任务,大功能会组织成一轮迭代。

## 桌面体验

- **快捷启动器**:按下快捷键(默认 Ctrl+Space,可在设置中修改)随时唤出一个轻量输入框,问完即走,几分钟内再次唤出可继续上一段对话。
- **系统托盘**:关闭窗口可选择缩到托盘继续待命,点击托盘图标即刻恢复。
- **多设备同步**:普通聊天在登录同一账号的所有设备间自动同步;在一台设备上的操作(改名、删除)也会同步。
- **账号数据隔离**:每个账号的数据独立保存;退出登录不会丢失任何数据,同一台电脑上的不同账号互不可见。
- **自动更新**:Windows 版会自动检测并安装新版本;macOS 版请下载新安装包更新。
- **图片查看**:对话中的图片可双击在独立窗口中放大查看。

## 安全与隐私

- 与 AI 模型的通信由你的电脑直接发起,对话内容不经过 Flairy 服务器中转;服务器只负责下发配置和同步会话。
- 所有可能改动电脑的操作(写文件、运行命令等)都需要你逐条确认;纯读取类操作(搜索、读网页、看文件)无需确认。
- 密钥等敏感凭证加密存放在本机,不会以明文写入磁盘。

## 常见问题速查

- **怎么换模型?** 输入框左下角的模型选择器。
- **怎么开启 Telegram?** 设置 → Telegram,按提示配对机器人。
- **定时任务在哪管理?** 设置 → 定时任务。
- **怎么给 Flairy 一个文件夹?** 新建对话时选择项目,或在侧边栏创建项目并选择文件夹。
- **对话没同步?** 确认两台设备登录的是同一账号;项目对话不参与同步,属正常现象。
- **想让 Flairy 忘记某件事?** 直接告诉它「忘掉……」即可。
